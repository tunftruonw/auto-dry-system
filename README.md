# Automactic Dry System (Smart Laundry Rack)

An automated laundry rack system designed to collect environmental changes (rain, humidity, temperature, light) and automatically control the rack to protect clothes. This project is implemented using C/C++ on an embedded platform (ESP8266) and using AI with environment input to making decision.

## 🎯 Project Purpose

This repository is built as a reference project and educational resource to support software engineering and embedded systems students at **FPT University** taking the **IOT102 (Internet of Things)** course. 

The project demonstrates practical applications of:
* Sensor data acquisition (Rain and Humidity sensors).
* Hardware actuator control (Stepper motors/Servo motors for rack movement).
* Decision-making logic using external APIs (such as Gemini API for advanced weather confirmation).

## 🪜 How to use
- Install ESP8266 Add-on in Arduino IDE.
- Import libraries into Arduino IDE.
- Config your own wifi and AI API.
- Connect the hardware as diagram.
- Plug and upload code to make your system alive.
